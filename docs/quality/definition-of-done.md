# Definition of Done

Une modification est terminée lorsque tous les points applicables sont satisfaits :

- les critères fonctionnels et cas d'erreur sont implémentés ;
- les frontières d'architecture sont respectées ;
- les tests attendus par la matrice sont ajoutés et réussissent ;
- lint, typecheck et build réussissent lorsqu'ils sont disponibles ;
- les libellés d'interface existent en français, anglais et espagnol ;
- l'interface concernée est utilisable sur mobile, au clavier et avec des noms accessibles ;
- aucune régression de performance connue n'est introduite sans décision explicite ;
- les secrets, autorisations, entrées et politiques RLS concernés ont été vérifiés ;
- les documents vivants, README et maquettes affectés sont synchronisés ;
- le travail se trouve sur une branche dédiée et la pull request cible la branche définie par le Git Flow ;
- la procédure de validation utilisateur indique les commandes exactes, les résultats attendus et les tests manuels ou visuels applicables, ou précise explicitement qu'aucun test visuel n'est nécessaire ;
- les changements utilisateur sans rapport sont préservés ;
- le compte rendu final cite les vérifications exécutées et les limites restantes.

Une vérification indisponible n'est pas un succès. Elle est indiquée comme non exécutée avec sa raison.
