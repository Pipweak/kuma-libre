# Maquettes UI V2 — Kuma Libre

Cette deuxième direction reprend le parcours fonctionnel de la V1 avec un langage plus graphique, expressif et tactile. Elle reste une référence de conception en HTML/CSS/JS, sans dépendance ni composant de production.

## Direction visuelle

- palette indigo, menthe, soleil et corail, distincte des marques de référence ;
- boutons épais avec retour tactile immédiat ;
- cartes arrondies, aplats colorés et formes décoratives ;
- mascotte Kuma originale utilisée comme guide ponctuel ;
- états correct et erreur compréhensibles par le texte et les icônes, pas seulement par la couleur ;
- aucune série quotidienne, monnaie virtuelle, classement ou mécanique punitive.

## Écrans

1. accueil et reprise rapide ;
2. configuration de la passe ;
3. question ;
4. réponse correcte ;
5. réponse incorrecte ;
6. progression dans les deux sens ;
7. menu secondaire ;
8. fin de passe ;
9. adaptation bureau.

## Consultation

Ouvrir `index.html` dans un navigateur. Le sélecteur **Planche / Prototype** change de mode et les boutons de l'interface permettent de parcourir le flux. Un écran précis peut être ouvert avec `index.html?view=focus&screen=quiz`.

Les fichiers `preview-board.png`, `preview-full.png` et `preview-mobile.png` donnent respectivement un aperçu de la planche, la planche complète et l'accueil en mode prototype.

## Intention

La V2 emprunte aux applications d'apprentissage leur clarté tactile et leur feedback positif, mais conserve la philosophie de Kuma Libre : le quiz est l'activité principale et le décor ne doit jamais concurrencer la question.
